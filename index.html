Featured Project

'마음토닥' (Maum-Todak)

로컬 LLM 기반의 MBTI & 별자리 심리상담 챗봇

프로젝트 시연 및 배포

GitHub 소스 코드 확인 챗봇 UI 시연 바로가기

1. 프로젝트 개요

'마음토닥'은 사용자의 PC에서 독립적으로 실행되는 로컬 AI 웹 애플리케이션입니다. 외부 API 없이 프론트엔드(화면), 백엔드(서버), AI 모델(Ollama)이 사용자의 컴퓨터 내에서 데이터를 주고받으며 작동하여, 비용 부담 없이 안전하게 개인적인 고민을 털어놓을 수 있는 환경을 제공합니다.

2. 전체 아키텍처 (구조)

사용자 (Browser)

index.html을 통해 입력을 하고 응답 화면을 표시합니다. (Frontend)

웹 서버 (Flask)

app.py가 실행되며 사용자 요청을 처리하고 대화 맥락(Context)을 관리합니다.

AI 엔진 (Ollama)

로컬 PC의 Ollama가 gemma3:4b 모델을 구동하여 답변을 생성합니다.

3. 단계별 작동 흐름

1
사용자 입력 (Frontend)

코드 위치: templates/index.html & JS

  • 사용자가 MBTI, 별자리, 기분을 입력 후 전송
  • 화면에 말풍선 즉시 표시 및 중복 전송 방지(버튼 비활성화)
  • fetch('/generate')로 백엔드에 데이터 전송
2
요청 처리 및 프롬프트 구성 (Backend)

코드 위치: app.py (generate 함수)

  • 세션(Session)으로 이전 대화 내용 기억 (최근 10개)
  • "너는 다정한 친구 마음토닥이야" 페르소나 설정
  • 사용자 정보(MBTI 등)를 프롬프트에 주입하여 맞춤형 답변 유도
3
AI 답변 생성 (Local LLM)

통신: localhost:11434 (Ollama)

  • 서버가 로컬 Ollama API에 요청 전송
  • gemma3:4b 모델이 대화 맥락을 파악하고 텍스트 생성
  • 인터넷 연결 없이 내부망(Localhost)에서만 처리됨
4
응답 반환 및 화면 표시 (Frontend)

기능: TypeWriter Effect

  • AI의 답변을 한 글자씩 타자 치는 효과로 출력
  • 답변 완료 시 입력창 재활성화하여 다음 대화 준비

4. 핵심 기능 요약

🔒 완전한 로컬 구동

외부 API(OpenAI 등)를 쓰지 않고 localhost 통신만 하므로 데이터 유출 걱정이 없으며 비용이 발생하지 않습니다.

🧠 대화 기억 (Context)

단순 1회성 답변이 아닌, Session을 통해 이전 대화 흐름을 기억하고 문맥에 맞는 자연스러운 답변을 제공합니다.

🛡️ 보안 설정

비밀 키(SECRET_KEY)를 코드에 직접 적지 않고 .env 환경변수로 분리하여 GitHub에 배포해도 안전합니다.

5.3 핵심 피드백 및 기술적 개선 전략 (Retrospective)
피드백 1: MBTI 특성 반영 부족

"MBTI의 개별적 특성을 깊이 고려하지 못했다. 단순히 4글자 유형만으로는 사용자 맞춤형 조언에 한계가 있음."

🚀 개선 전략: RAG (검색 증강 생성) 도입

단순 프롬프트 주입 방식을 넘어, MBTI 성격 유형별 상세 데이터베이스(Vector DB)를 구축하고 RAG 기술을 적용하겠습니다. 이를 통해 AI가 답변 생성 시 관련 심리학적 특성 정보를 실시간으로 검색/참조하여 더 전문적이고 깊이 있는 조언을 제공하도록 고도화할 계획입니다.

피드백 2: AI 페르소나 이탈(Drift) 현상

"대화 도중 AI가 설정된 성격(말투, 역할)을 유지하지 못하고 이탈하여 사용자를 당황하게 함."

🚀 개선 전략: System Prompt 강화 & Context 관리

대화 턴(Turn)이 길어질수록 시스템 지시사항이 희석되는 문제를 해결하기 위해, 매 턴마다 핵심 페르소나 지침을 재주입하는 System Prompt Reinforcement 기법을 적용하겠습니다. 또한, 대화 기록(Context History)에서 오래된 내용을 요약(Summarization)하여 토큰 제한 내에서 성격 유지 성능을 극대화할 것입니다.
